takayukisakai.com — content editor

はじめに、GitHubのアクセストークンをひとつ。
トークンはこの端末のなか（localStorage）にだけ保存されます。

作り方：github.com/settings/personal-access-tokens/new を開く →
① Token name: 「site-editor」など適当に ／ Expiration: 1 year
② Repository access: Only select repositories → takayukisakai-site を選択
③ Permissions → Repository permissions → Contents を Read and write に
④ 「Generate token」→ 表示された github_pat_… をここに貼る

サイトを見る →

保存すると自動でビルドが走り、1〜2分でサイトに反映されます。
